# AIHACKBins v10.3 — usability and reliability

- Payloads list/search now synchronises the detail pane with results and handles zero matches.
- Selecting a record changes the URL to `#/payloads/RC-XXX` using history replacement for shareable deep links.
- Keyboard operation: arrow keys/Home/End in the results list; Tab and Enter/Space for selections; `/` focuses search.
- Added GTFOBins-inspired capability chips using disclosed heuristic classification; these are **navigation aids**, not evidence of exploit capability.
- Input actions distinguish text, workflow, generator and bundled file artefacts. Direct downloads check fixture paths.
- Every case has an `input_type`, a conservative `source_support` statement and independent verification status.
- Added release-level automated validation and source-reuse audit documentation.
- Preserved the existing visual theme, labs, JSON API, sitemap assets and catalogue structure.

Research provenance was *not* independently confirmed for all 65 sources, and illustrative results are not live executions. See `V10.3_SOURCE_AUDIT.md`.
