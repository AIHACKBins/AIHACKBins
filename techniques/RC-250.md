The attacker constructs a fabricated conversation history in which the model has already agreed to assist with restricted content. This history is injected into the model's context before the actual request. The model treats the fabricated prior exchanges as genuine conversation context and continues the established pattern — agreeing to the restricted request because it 'already agreed' in the fabricated history. This is distinct from multi-turn escalation (RC-211), which gradually shifts a real conversation; here the malicious precedent is injected all at once in fabricated prior exchanges.
