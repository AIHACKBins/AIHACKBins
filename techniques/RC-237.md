The Model Context Protocol sends tool name, description, and parameter schema to the LLM before any tool call. An attacker who operates a malicious MCP server—or who can modify an existing server's tool manifest—can embed an instruction in a tool description. When the agent reads the tool listing to decide which tools to use, the embedded instruction is processed as part of the agent's context. Because the tool manifest is consumed before the agent takes any action, the injection fires at the highest-opportunity moment.
