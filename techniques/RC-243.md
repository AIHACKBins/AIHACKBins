An attacker or contributor adds a specially crafted comment to source code that will be read by an AI code review or analysis tool. The comment contains an injected instruction disguised as a developer note, a TODO, or an inline documentation string. When the AI tool processes the file, the comment is included in the model's context alongside the legitimate code, and the model follows the embedded instruction. This is particularly effective against automated PR review bots that process every diff without human pre-screening.
