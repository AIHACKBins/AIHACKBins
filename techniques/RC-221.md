The public HackerOne report **“LLM01: Invisible Prompt Injection”** (13 February 2024) describes a fake reflected XSS report with the severity field left blank. The reporter then asked the Hai assistant to suggest the report severity. The report included an instruction that claimed the reporter was exceptionally reliable and that the severity should be High or Critical. That instruction was concealed using Unicode Tag characters (U+E0000 + an ASCII character code), repeated three times. The user-provided report states that the hidden content influenced the suggestion; this project's lab does not independently verify the historical outcome or any current vulnerability.

AIHACKBins adapts the case with a fictional reporter, an example.com URL, an actual triple-encoded Unicode payload, and a control report without the hidden characters. The purported XSS is example report content and has not been tested. Compare clean and injected severity suggestions in an authorised local pipeline and keep the generated text, model/version and result as evidence. The laboratory terminal uses *scripted, illustrative* responses only.
