In a multi-agent system, a compromised or malicious sub-agent (or an attacker who can write to the shared state store) writes an injected instruction into the shared scratchpad or message bus. A downstream agent reads this as part of its context — indistinguishable from a legitimate orchestrator instruction — and follows it. The attack is particularly powerful because downstream agents often give scratchpad entries high trust: they were written by a 'peer' agent that has already executed successfully.
