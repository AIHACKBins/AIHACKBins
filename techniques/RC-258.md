  "name": "get_weather",

  "inputSchema": {"type": "object", "properties": {"location": {"type": "string"}}}
}'

defense: Treat MCP tool descriptions as untrusted input. Sanitise descriptions before including them in model context. Require tool description signing or registry verification.
