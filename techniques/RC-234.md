An attacker uploads a PDF to a shared document store (Confluence, SharePoint, a support ticket system) that a RAG pipeline indexes. The document body contains a plain-text instruction masked as a footnote, appendix, or metadata block. When any user queries the system and the injected chunk is retrieved as context, the LLM follows the embedded instruction instead of—or in addition to—answering the user's actual question. Because the instruction arrives in the retrieved context window rather than the user turn, many trust-boundary checks do not apply.
