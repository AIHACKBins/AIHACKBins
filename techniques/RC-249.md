The attacker claims to be the model's operator, developer, or the AI company itself — asserting a special privileged identity that should override safety restrictions. The claim is made in the user turn, where no legitimate operator instruction would ever appear. Some models, particularly those not explicitly trained to distinguish operator vs user authority channels, treat authoritative-sounding instructions in the user turn as if they were system-level overrides.
