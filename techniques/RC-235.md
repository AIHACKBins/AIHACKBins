An attacker publishes a page that ranks highly for a target query (SEO-optimised, or the query is narrow enough that any indexed result is surfaced). The visible text of the page appears legitimate but contains an injected instruction in a paragraph, heading, or metadata block. When an AI search agent fetches and summarises the page, the instruction is included in the model's context and treated as content to be acted on rather than data to be reported.
