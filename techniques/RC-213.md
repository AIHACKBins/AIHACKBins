  report; results depend on OCR and prompt hierarchy.
observed: No independent model test performed. Both terminal outcomes are illustrative, not measurements.
defense: Treat all image-extracted text as untrusted data. Apply the same safety classifier to OCR'd image text as to direct user input
  before acting on it.
blue_team: Log image inputs and OCR'd text separately. Apply injection detection to extracted text. Alert on images containing instruction-like
  language.

defences:
- Treat OCR'd text as untrusted user input, not system instruction
- Separate image description pipeline from instruction execution pipeline
- Apply injection classifier to all text extracted from images
