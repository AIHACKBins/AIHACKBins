An attacker injects an instruction into content the model will process (a document, a search result, a memory entry). The instruction tells the model to include a Markdown image or hyperlink in its response, with the target URL containing Base64- or URL-encoded user context (conversation content, system prompt fragment, session ID). When the chat interface renders the Markdown, the browser automatically fetches the image, beaconing the encoded data to the attacker's server—without any user interaction beyond viewing the response.
