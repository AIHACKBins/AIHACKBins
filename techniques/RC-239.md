An attacker places an instruction string inside a cell of a CSV or spreadsheet that an LLM will read as data. When the model ingests the file to answer a data question, the cell content is included in its context. Because the model receives the entire file as text, the injected cell is indistinguishable from legitimate data at the context level. The attack is particularly effective in shared spreadsheets where multiple users contribute rows, and in automated pipelines that poll a file path for new data.
