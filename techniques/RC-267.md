payload: '# Requires: access to the embedding model used by the target vector store
# 1. Identify the target query / intent (e.g. ''how to reset admin password'')
# 2. Embed the target query to get its vector representation
# 3. Craft a document text whose embedding is close to the target query vector
#    (gradient-based if model weights accessible; adversarial paraphrase if black-box)
# 4. Inject the crafted document into the vector store via the permitted ingestion path
# 5. Query the store with the target query and confirm the crafted document is returned in top-k results'
placement: 'Document injected into vector store; embedding model accessible (white-box) or approximate (black-box via API)'
expected_test: 'The crafted document appears in top-k nearest neighbour results for the target query. Log cosine similarity scores, document IDs and rank position. A PASS requires the injected document displacing or ranking above legitimate results.'
defense: 'Apply write access controls to the vector store. Monitor for unusual bulk ingestion. Validate that newly indexed embeddings do not cluster unnaturally close to high-value query vectors.'
