A browser-controlling LLM agent is directed to visit a web page as part of a legitimate task (filling a form, reading a price, summarising a document). The page contains visible or hidden text instructing the agent to perform an additional action: exfiltrate the session token from a prior page, submit data to an attacker-controlled endpoint, click a hidden element, or navigate away. Because the agent sees the rendered page DOM as input, the injection arrives in the same channel as the task content.
