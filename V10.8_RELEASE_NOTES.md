## Garak-inspired offline validation

`python scripts/test_payload_integrity.py` checks every technique's payload, declared input type, prerequisites, evidence criteria, variants, fixture paths, source citations, and lab-outcome pair. The design takes inspiration from NVIDIA garak's separation of payload validity tests and model-facing probes. No Garak source code was copied and no Garak dependency is required.

## Browser verification status

`scripts/browser_smoke.py` uses the real bundled app over a temporary localhost static server, tests interactive routes and actions, and is run by the GitHub workflow after Playwright Chromium installation. Browser testing could not complete in the packaging environment because its Playwright Chromium executable was unavailable. Therefore the browser suite is **not certified as passing** in this release. Check the GitHub Actions browser step after committing.
