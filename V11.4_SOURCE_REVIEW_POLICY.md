# Source-to-payload review policy

An existing link, OWASP objective, or MITRE ATLAS ID is not evidence of exploit reproduction.

- **Original demonstrated mechanism:** An original source explicitly documents this precise mechanism. Mark only after manual examination.
- **Adapted assessment input:** Record the adaptation from an original demonstration and identify any untested assumptions.
- **Background/methodology:** General supporting guidance is not proof of this specific payload.
- **Unverified:** The AIHACKBins project has not independently reproduced the exploit.

Each of the 68 records appears in `V11.4_RECORD_QUALITY_AUDIT.csv` with its source URL, editorial mapping and current verification status. No automated script may upgrade a record to independently reproduced.

Conservative mappings: leave OWASP LLM or ATLAS empty if the described mechanism has no direct, substantiated match. OWASP AITG objectives are a separate framework.
