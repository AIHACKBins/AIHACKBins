# AIHACKBins v11.5 — Verification, Reporting and Responsible Use

This is a complete static Cloudflare Pages release built on v11.4. The existing Concrete design and all 68 research cases, payloads and illustrative labs remain intact. No new RC entries were added.

## Changes

- Added `RESPONSIBLE_USE.md`, plus visible non-intrusive legal/responsible-use links in the footer and About page. This disclaimer is educational information, not a substitute for legal advice, and does not guarantee immunity from liability.
- Added target-specific Baseline shortlists for Chatbot, AI application/RAG, AI agent/MCP and AI model/data/infrastructure. All 32 AITG objectives remain visible under All targets; these shortlists are editorial suggestions, not comprehensive assessment certification.
- Added client-side Markdown Baseline assessment-note export and a per-technique Markdown evidence-note template. Neither feature uploads or stores target data; both start with unverified placeholder outcomes.
- Added related ecosystem references for lolol.farm and LOLSkills in About. lolol.farm is a cross-project discovery directory, not the source of AIHACKBins payloads; no external project endorsement or affiliation is implied.
- Corrected `data/SCHEMA.md` from 65 to 68 canonical cases.
- Added `scripts/validate_mapping_policy.py` to the single GitHub Actions workflow.
- Extended browser smoke checks for target filters, Markdown exports, evidence-note exports, and the responsible-use information. Browser success is not claimed unless the workflow runs and passes.

## Checks

Five offline validators and JavaScript syntax checks passed locally against the extracted release. All 68 illustrative lab pairs and the 32 AITG objectives remain present. The browser suite must be executed in an environment where Chromium can navigate to the local test server; if unavailable, its outcome is *not verified*.

## Evidence limitations

This is an assessment reference, not a verified exploitation database. Source-to-payload alignment and framework semantics still require manual scholarly and expert review. No authored lab output is presented as a live finding, and no real-world exploit claims were added.
